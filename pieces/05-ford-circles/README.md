# The Rational Shore

Ford circles tile the rational number line: every reduced fraction p/q
(with gcd(p, q) = 1) defines a circle of radius 1/(2q²) tangent to the
x-axis at x = p/q. Two of these circles are **externally tangent** if and
only if their fractions are adjacent in some Farey sequence — equivalently,
if |pq′ − p′q| = 1.

The result is an infinitely self-similar packing: the gaps between any two
tangent circles are themselves filled by a unique inscribed circle, then the
next gap is filled, and so on forever. This piece renders all Ford circles
for denominators q ≤ 60 (1 103 circles total), clipping the boundary circles
at 0/1 and 1/1 to reveal the classic Gothic-arch silhouette.

## Enumeration

Fractions are generated by an iterative Stern-Brocot tree traversal. Starting
from the adjacent pair (0/1, 1/1), the mediant (a+c)/(b+d) is inserted between
every adjacent pair (a/b, c/d) whose denominator sum does not exceed max_q.
This produces each reduced fraction exactly once, in O(|F_n|) time with no
duplicate checking.

```
ford_fractions(max_q):
    result = [(0,1), (1,1)]
    stack = [(0, 1, 1, 1)]
    while stack:
        a, b, c, d = stack.pop()
        p, q = a + c, b + d
        if q <= max_q:
            result.append((p, q))
            stack.push((a, b, p, q))
            stack.push((p, q, c, d))
```

## Ford circle geometry

For each fraction p/q the Ford circle has:

```
center = (p/q,  1/(2q²))
radius = 1/(2q²)
```

The circle is tangent to the x-axis from above (center height equals radius),
so every circle rests on the same baseline.

## Tangency proof sketch

Circles C(p/q) and C(p′/q′) are externally tangent iff the Euclidean distance
between their centers equals the sum of their radii:

```
distance² = (p/q − p′/q′)² + (1/(2q²) − 1/(2q′²))²
           = ((pq′−p′q)/(qq′))² + ((q′²−q²)/(2q²q′²))²
```

When |pq′ − p′q| = 1 this simplifies to (q² + q′²) / (2q²q′²) = (1/(2q²) + 1/(2q′²))²,
confirming tangency. The pattern therefore self-organises entirely from
the arithmetic of fractions.
